# Portafolio · Jennyfer Choque Quintero

Portafolio personal de **Jennyfer Choque**, desarrolladora Full Stack Java Jr. (Lima, Perú).

**En vivo:** https://jeechq-del.github.io/My-portfolio/

## Secciones
Inicio · Proyectos · Sobre mí · Stack · Trayectoria · Formación · Blog · Contacto

## Tecnologías
- HTML5 semántico, CSS3 (Grid, Flexbox, variables, responsive) y JavaScript vanilla
- IntersectionObserver para animaciones y para resaltar la sección activa del menú
- Tipografías: JetBrains Mono, Public Sans y Lobster (Google Fonts)
- Íconos: Devicon
- Hosting: GitHub Pages (HTTPS)

## Estructura
```
index.html
css/styles.css     estilos generales (paleta del moodboard)
css/post.css       estilos de los artículos
js/main.js         menú, scroll, animaciones y formulario
blog/*.html        artículos del blog
assets/img/        foto y capturas de proyectos
assets/docs/       CV en PDF
```

## Ejecutar en local
Abre `index.html` en el navegador o usa la extensión *Live Server* de VS Code.
