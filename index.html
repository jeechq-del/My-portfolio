FULL STACK · PROYECTO FINAL EN EQUIPO sep – dic 2026

MiCancha · Reserva de canchas deportivas

Plataforma web para encontrar, comparar y reservar canchas deportivas en Colombia y Perú, con frontend en JavaScript y backend en Java y Spring Boot. Resuelve un problema real: la oferta está dispersa y cada complejo publica sus horarios y precios por separado.

  • Backend: implementé las capas de Usuario (repository, service, controller y DTO) con Spring Boot y JPA.
  • Roles: creé el DTO y el controller de Roles para los niveles de acceso de la plataforma.
  • Frontend: desarrollé el inicio de sesión y registro con LocalStorage y un servicio de sesión reutilizable que inicia sesión al registrarse.
  • Aporté a las páginas Nosotros (misión y visión) y Catálogo (7 canchas con sus precios).

// el reto

Coordinar a cinco personas trabajando en el mismo sitio sin pisarnos el código. Lo resolvimos con una rama por pantalla, commits pequeños y Pull Requests revisados por otra persona antes de unirlos a main.

// en equipo: base de datos MySQL de 5 entidades (roles, usuarios, deportes, canchas y reservas), catálogo dinámico con JavaScript y prototipo en Figma.

WEB APP · PROYECTO INDIVIDUAL oct – nov 2026

TaskFlow · Planificador de tareas

Aplicación para crear, asignar y organizar tareas por estado, inspirada en Trello y ClickUp. La construí sola durante el Sprint 2 del bootcamp para practicar JavaScript orientado a objetos.

  • Clase TaskManager con métodos para agregar, listar, filtrar por estado, actualizar, asignar y eliminar tareas.
  • Validación del formulario con mensajes de error claros.
  • Las tareas se muestran como tarjetas, cada una con un ID único autoincremental.
  • Pruebas de la lógica en una página de tests dedicada.

// el reto

Mantener sincronizados los datos y la pantalla: al eliminar una tarea había que quitarla del arreglo y de la vista a la vez. Lo resolví concentrando la lógica en la clase TaskManager y dibujando las tarjetas a partir de sus datos.

// mi aporte: proyecto 100% mío: diseño, lógica, validaciones y pruebas.
